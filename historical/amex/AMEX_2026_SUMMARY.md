## 📤 How to Post to Shopify

### Option 1: Manual Copy-Paste (5 minutes)
1. Open [american_express_2026.html](american_express_2026.html)
2. Copy the **ENTIRE** file contents
3. Go to Shopify Admin → Online Store → Pages
4. Click "Add page"
5. Title: "The American Express 2026 - Betting Preview"
6. Click "Show HTML" button (< >)
7. Paste the entire HTML
8. Click "Save"
9. Preview and publish!

### Option 2: Automated Deploy (10 minutes setup)
Use the deployment script:
```bash
python3 scripts/deploy_to_shopify.py --html american_express_2026.html
```

Requires:
- Shopify Admin API token
- Store URL in .env file
