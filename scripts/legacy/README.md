# Legacy / deprecated scripts

These storyline generators are **deprecated**. The weekly pipeline uses:

- **Primary:** `generate_ai_storylines_claude.py` (with `ANTHROPIC_API_KEY`)
- **Fallback:** `generate_storylines.py`

Scripts in this folder are kept for reference or one-off use:

- `generate_ai_storylines.py` – older AI storylines (AMEX defaults)
- `generate_ai_storylines_batch.py` – batch variant
- `generate_intelligent_storylines.py` – intelligent storylines
- `generate_storylines_with_datagolf.py` – Data Golf–based storylines

Run from **project root** if you use them.
